# CLI Contacts Book 📒

A lightweight, reliable command-line contact manager written in Python with persistent JSON storage.

## Features
- **Persistent Storage**: Automatically saves and loads contacts from a local JSON file (`contacts.json`).
- **Input Validation**: Prevents empty names, empty phone numbers, or empty search queries.
- **Duplicate Protection**: Prompts for confirmation before overwriting an existing contact.
- **Error Handling**: Safely handles corrupted or empty JSON files without crashing.
- **Case-Insensitive Search**: Find contacts by partial name match or exact phone number.

## Requirements
- Python 3.6+ (uses only standard library modules: `json`, `os`).
